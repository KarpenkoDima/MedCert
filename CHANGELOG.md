# Changelog: MedCert

## [v2.1.0] — 2026-01-17

### Добавлено

* Внедрение Dependency Injection (DI) для управления жизненным циклом `LiteDatabase` (регистрация как Singleton).
* Использование Constructor Injection в репозиториях и `UnitOfWork`.



### Изменено

* Глубокий рефакторинг `UnionOfWork` и `BaseRepository` для поддержки внедрения зависимостей через интерфейс `ILiteDatabase`.
* Оптимизация работы с базой данных: удалена избыточная логика обработки строк подключения внутри репозиториев.



### Исправлено

* Устранены проблемы с блокировкой базы данных (database locking issues), возникавшие во время выполнения юнит-тестов.

---

## [v2.0.0] — 2025-12-25

### Добавлено

* 
**Паттерн Unit of Work**: Реализован интерфейс `IUnitOfWork` и класс `UnitOfWork` для координации транзакций и работы нескольких репозиториев (`Customers`, `Doctors`, `Logs`).


* 
**Юнит-тестирование**: Создан отдельный проект `MedCert.Tests` на базе NUnit и Moq, включающий 22 теста для проверки `PrintService`, репозиториев и логики транзакций.


* 
**Надежность печати**: Добавлены методы `IsFileLocked` и `TryCloseWordProcess` для предотвращения ошибок доступа к файлу `output.doc`, если он открыт в MS Word.


* Новый файл документации `IMPROVEMENTS.md` с детальным описанием архитектурных изменений.
