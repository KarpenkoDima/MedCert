## 1. Проверка блокировки файла перед печатью

### Проблема
При повторной печати сертификата приложение могло выдавать ошибку, если файл `output.doc` был открыт в Microsoft Word.

### Решение
Добавлены методы в `PrintService.cs`:

#### `IsFileLocked(string filePath)`
- Проверяет, заблокирован ли файл другим процессом
- Использует попытку открытия файла с эксклюзивным доступом

#### `TryCloseWordProcess(string filePath)`
- Автоматически закрывает процессы Word, удерживающие файл
- Сначала пытается корректно закрыть окно, затем принудительно завершает процесс

### Преимущества
✅ Предотвращение ошибок при повторной печати
✅ Автоматическое решение проблемы блокировки файлов
✅ Улучшенный пользовательский опыт
✅ Детальное логирование процесса

### Файлы
- `WindowsFormsApp1/Services/PrintService.cs` (строки 37-143)

## 2. Реализация паттерна Unit of Work

### Описание
Добавлена реализация паттерна Unit of Work для управления транзакциями и координации работы нескольких репозиториев.

### Компоненты

#### `IUnitOfWork.cs`
Интерфейс определяет:
- Доступ к репозиториям (Customers, Doctors, Logs)
- Управление транзакциями (BeginTransaction, Commit, Rollback)
- Сохранение изменений (SaveChanges)

#### `UnitOfWork.cs`
Реализация паттерна для LiteDB:
- Управление временем жизни подключения к БД
- Координация транзакций между репозиториями
- Автоматический откат незафиксированных транзакций при dispose
- Интеграция с логированием

### Преимущества
✅ Обеспечение согласованности данных
✅ Поддержка транзакций
✅ Централизованное управление подключением к БД
✅ Упрощение работы с несколькими репозиториями

### Файлы
- `WindowsFormsApp1/Data/IUnitOfWork.cs` - интерфейс
- `WindowsFormsApp1/Data/UnitOfWork.cs` - реализация
- `WindowsFormsApp1/Program.cs` (строка 65) - регистрация в DI

### Пример использования

```csharp
using (var uow = serviceProvider.GetRequiredService<IUnitOfWork>())
{
    uow.BeginTransaction();

    try
    {
        uow.Customers.Add(customer);
        uow.Logs.Add(logEntry);
        uow.Commit();
    }
    catch
    {
        uow.Rollback();
        throw;
    }
}
```

    public void ComplexOperation()

        _unitOfWork.BeginTransaction();

        {
            // Несколько операций с БД

            _unitOfWork.Logs.Add(logEntry);
